02 — 功能

手机 App 里常用的，都在这儿。

一键开关机

菜单栏显示当前设定温度，点开面板，电源键就在右上角。

精确调温

16–30℃，每档 0.5°。拖动滑块松手后才下发，不会连发一串命令。

模式与风速

自动、制冷、除湿、制热、送风；风速五档，外加上下 / 左右扫风。

节能与强劲

一个开关切节能，一个卡片开强劲，状态实时回读。

室内外温度

面板顶部直接显示空调传感器读到的室内、室外温度。

本地直连

蓝牙点对点通信，不登录账号、不上传数据，断网也能用。

03 — 原理

界面和蓝牙，各管各的。

MideaBar 只负责界面。蓝牙连接交给后台程序 midea-ac-agent，两者通过一行一条的 JSON 对话。按 通信协议 实现一个后台，就能换掉它。

MideaBar

菜单栏图标与控制面板，乐观更新，失败自动回滚。

04 — 安装

三步，从源码构建。

需要 macOS 14 及以上和 Xcode 命令行工具。也可以直接从 Releases 下载打包好的 App，再把 midea-ac-agent 放到 ~/.local/bin。

获取源码

git clone https://github.com/binaryify/MideaBar.git
cd MideaBar

打包并启动

把后台程序的路径传给 AGENT，它会被放进 App 包里。

make run AGENT=/path/to/midea-ac-agent

允许蓝牙权限

首次启动时 macOS 会请求蓝牙权限，点允许。之后把 build/MideaBar.app 拖进「应用程序」，通过 Finder 打开即可。
